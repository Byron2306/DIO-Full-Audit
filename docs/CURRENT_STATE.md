## Current Design Choice

The suite is intentionally adapter-first.

Do:

- Reference existing projects by path.
- Generate small job packets.
- Generate reviewable output folders.
- Keep receipts for every adapter call.

Do not:

- Copy full repos.
- Copy `node_modules`.
- Copy old databases.
- Render videos during Phase 1.
- Send emails automatically.
- Use real client data before redaction and approval gates are added.
