# Product Layers

The suite is stratified into product layers so each offer can be sold, routed, and marketed separately while sharing the same AutoRelease spine.

## Layers

```text
Inbox / form / file intake
-> product route
-> review pack
-> approval gate
-> product-specific output
-> campaign/learning feedback
```

Configured in:

```text
config/product_layers.json
```

## Current Layer Roles

- **Evidex**: first productized cash offer.
- **HOMS**: education marking route and next high-value vertical.
- **Outlook Triage**: intake router and standalone inbox-control offer.
- **VAMP**: performance evidence vertical, next adapter.
- **Sophia**: controlled commercial pilot for grounded Gemini academic section reviews with payment, human approval, and governed Outlook delivery.

## Phase 3 Purpose

Phase 3 uses NicheFoundry as the campaign engine for each layer.

Each product gets:

- Campaign brief.
- Landing page outline.
- Short posts.
- Lead magnet outline.
- Short video script.
- Storyboard.
- Visual plan.
- Publishing metadata.
- Editorial approval checklist.

No media rendering is required in Phase 3. Storyboarding and approval come first.
