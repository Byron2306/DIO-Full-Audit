# HOMS Afrikaans Route: Root Cause and Release Report

## Outcome

The Afrikaans Grade 12 route now builds a complete, source-first language assessment instead of adapting generic visual-source questions. The verified release candidate contains two complete Afrikaans texts, a comprehension section, a summary section, a language section, and a matching Afrikaans memorandum.

## Root Causes

1. The quoted meta-assessment questions were hard-coded in `scripts/build_homs_core_subject_smoke_packs.py`. They were not generated by NIM and were never valid learner-facing Afrikaans questions.
2. The newer provider route demanded that rubric marks independently equal the complete paper total. That is inappropriate for a memo-marked language paper and caused valid provider output to be rejected.
3. Full-paper generation was attempted in one provider response. NIM DeepSeek produced a truncated response, so the JSON could not be parsed.
4. The default provider model was Nemotron instead of the requested NIM DeepSeek model.
5. CAPS resolution had no explicit `afrikaans_language` aliases and requested an English-preferred document, so the authoritative Afrikaans FAL source was not reliably selected.
6. The formatter still treated language papers as generic visual assessments, exposing planner language and internal provenance while creating irrelevant source placeholders.

## Implemented Route

The repaired path is:

1. Resolve the authoritative Afrikaans FAL CAPS document.
2. Apply the Grade 12 Term 3 language blueprint.
3. Generate and validate complete Afrikaans source texts first.
4. Generate comprehension and summary sections separately.
5. Build language questions from reviewed, source-specific language targets.
6. Assemble the paper locally and reconcile marks.
7. Apply learner-facing A4 formatting.
8. Generate an Afrikaans memorandum.
9. Block release on semantic, language, source, or mark validation failures.

There is no deterministic generic-question fallback on this route. Provider or validation failure now blocks the learner paper instead of silently substituting smoke content.

## Permanent Gates

- Reject meta-assessment wording such as asking which source would make the strongest assessment question.
- Reject generic prompts about using a graph, diagram, photo, or image as evidence in Afrikaans.
- Require complete source text rather than source descriptions.
- Require the Afrikaans FAL CAPS document for the Afrikaans route.
- Require Afrikaans learner-facing content and memo content.
- Require the three-section language-paper shape.
- Require exact question-mark reconciliation.
- Keep internal smoke artifacts explicitly blocked from learner release.
