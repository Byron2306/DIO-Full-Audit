# HOMS Exam: randomized Grades 1–12 draft batch

The current HOMS Exam Studio source and review bundle is in [`deliverables/homs_random_grade_exam_set_20261101`](../../deliverables/homs_random_grade_exam_set_20261101/README.md). It contains a reproducible phase-randomized subject assignment, one draft exam and memo per grade, structured assessment JSON, official CAPS source hashes, a review dashboard and a ZIP for handoff.

The builder is [`scripts/build_homs_curated_grade_exam_set.py`](../../scripts/build_homs_curated_grade_exam_set.py). It reads the recorded random assignment and hash-verified CAPS manifest, rejects mark/memo mismatches, and writes the exam, memo and per-grade receipt. It does not call a language model or silently reuse rejected generated drafts.

The batch creates evidence that this HOMS Exam path produced artifacts for all 12 grades. It does **not** establish independent educator acceptance, complete term-by-term scope coverage, moderation, classroom approval, commercial validation or product-wide assessment quality. Every paper remains a draft for qualified subject educator review.
