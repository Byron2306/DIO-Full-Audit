# DIO Profile Library

Phase 0 freezes six profile classes only:

- `domains/`
- `frameworks/`
- `authorities/`
- `connectors/`
- `outputs/`
- `commercial/`

Concrete typed, source/version/hash-bound profiles are a **Phase 1** deliverable. Profiles are declarative configuration. They may not create authority, executors, product maturity, market validation or revenue proof.
