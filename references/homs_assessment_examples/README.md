  - Official DBE Dance SBA exemplar booklet.

## Formatter Lessons

- Internal pipeline labels must not appear in learner or teacher documents.
- Use simple cover metadata: subject, grade, assessment task, marks, time.
- Use `INSTRUCTIONS AND INFORMATION`.
- Use `QUESTION` headings and mark brackets such as `(5)`.
- Treat diagrams, charts, tables, and pictures as `VISUAL MATERIAL`.
- Put memo/rubric content under `MARKING GUIDELINE`.
- Keep machine receipts and formatter policy in JSON only.
